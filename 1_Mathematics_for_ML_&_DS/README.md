### Course Overview

- **Linear Algebra for Machine Learning and Data Science:**  
  Teaches representing data as vectors and matrices, performing algebraic operations (dot product, inverse, determinant), and applying eigenvalues and eigenvectors to ML problems such as Principal Component Analysis (PCA).

- **Calculus for Machine Learning and Data Science:**  
  Covers optimization of functions using derivatives and gradients, visual interpretation of differentiation, gradient descent for neural networks, and optimization using different activation and cost functions.

- **Probability and Statistics for Machine Learning and Data Science:**  
  Focuses on quantifying uncertainty in predictions, understanding probability distributions, applying statistical methods like Maximum Likelihood Estimation (MLE) and hypothesis testing, and assessing model performance using confidence intervals and margins of error.

### What's Included

- Intuitive visualizations and Python-based hands-on labs that apply mathematical principles to real machine learning workflows
