## Generative AI using Large Language Models (LLMs)

This course by deeplearning.ai, created in partnership with AWS, offers a practical and comprehensive introduction to generative AI using large language models (LLMs). It covers the fundamentals of LLM architectures, training, fine-tuning, and deploying models for real-world applications across industries.

### Course Overview

- **Generative AI Use Cases and Project Lifecycle:**  
  Introduces generative AI and LLM fundamentals, transformer architecture, training processes, prompt engineering, and generative configurations. Includes hands-on labs for real tasks like dialogue summarization.

- **Fine-Tuning and Model Evaluation:**  
  Covers methods for adapting pre-trained models to specific domains using fine-tuning and parameter-efficient fine-tuning (PEFT). Explains metrics to evaluate model performance with practical lab exercises.

- **Advanced Techniques: RLHF, RAG, and LangChain:**  
  Explores reinforcement learning with human feedback (RLHF) to align models with human preferences, retrieval-augmented generation (RAG), and integrating LLMs with API and custom data sources using LangChain.
